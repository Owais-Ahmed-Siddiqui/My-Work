# 🛍️ VogueStore — Full-Stack E-Commerce

VogueStore is a modern, high-performance shopping platform built for speed, security, and a premium user experience. It integrates a reactive frontend with a robust backend to provide a seamless end-to-end shopping journey.

### 🌟 Project Essence
A complete retail ecosystem that handles everything from product discovery to secure checkout, designed with a focus on clean code and scalable architecture.

### 🛠️ Core Tech Stack
*   **Frontend:** React 18 & TypeScript (UI/UX)
*   **Styling:** Tailwind CSS & Framer Motion (Design & Motion)
*   **Backend:** Django 5.1 & REST Framework (Logic & API)
*   **Database:** MongoDB (Scalable Data Storage)
*   **Auth:** JWT (Secure User Sessions)

### ✨ Key Capabilities
*   **Smart Catalog:** 40+ products across 8 categories with advanced filtering.
*   **Seamless Cart:** Persistent shopping experience with real-time updates.
*   **Secure Auth:** Full user registration, login, and profile management.
*   **Fluid Checkout:** Multi-step process for shipping, payment, and order tracking.
*   **Responsive Design:** Optimized for every screen, from mobile to ultra-wide desktops.
