# 📱 Socially — Mini Social Media App

Socially is a streamlined, fully-functional social networking platform designed for high engagement and seamless user interaction. It combines a modern, reactive frontend with a robust Django-powered backend.

### 🌟 Project Essence
Built to mimic the core features of modern social platforms, Socially focuses on real-time feedback loops (likes/comments) and an intuitive discovery system to connect users instantly.

### ✨ Key Features
*   **Dynamic Feed:** A real-time content stream featuring likes, comments, and media support.
*   **Interactive Profiles:** Personal user hubs for managing bio information and activity history.
*   **Social Graph:** A complete "Follow" system allowing users to build and curate their own networks.
*   **Post Creation:** Seamless multimedia posting with image support and instant updates.
*   **Trending Intelligence:** An automated section to highlight hot topics and popular users.
*   **Fluid UX:** Built with Framer Motion for premium animations and a fully responsive layout.

### 💻 Tech Stack
*   **Frontend:** React, TypeScript, Tailwind CSS, Framer Motion
*   **Backend:** Python, Django, Django REST Framework
*   **Database:** SQLite / PostgreSQL
*   **Icons:** Lucide React
