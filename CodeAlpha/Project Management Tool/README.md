# 🌊 Flowboard — Collaborative Work OS

A beautiful, high-performance team workspace that blends project management with a social pulse. Flowboard combines the structured power of a Kanban board with the real-time engagement of a social network.

### 🚀 The Vision
Flowboard is designed to make team collaboration feel alive. By integrating an activity feed directly into the workspace, it transforms project tracking from a list of chores into a shared journey.

### ✨ Core Capabilities
*   **Dynamic Kanban Engine:** Advanced drag-and-drop boards for seamless task movement across project pipelines.
*   **Deep Task Context:** Rich cards featuring checklists, priority levels, attachments, and nested comment threads.
*   **Social Activity Feed:** A real-time stream where team members post updates, like achievements, and @mention colleagues.
*   **Instant Collaboration:** Real-time presence indicators and live notification system (WebSockets).
*   **Warm UI/UX:** A gorgeous, Linear-inspired interface with 60fps animations and a dedicated command palette.

### 💻 Tech Stack
*   **Frontend:** React 19, TypeScript, Tailwind CSS 4, Framer Motion
*   **Backend:** FastAPI (Python), WebSockets, JWT Authentication
*   **State & Logic:** Zustand & @dnd-kit
