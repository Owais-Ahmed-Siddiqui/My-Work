# 💠 Cyber Business AI Assistant

A futuristic, high-performance AI consultant built with **Streamlit**, **Google Gemini 1.5 Flash**, and **Vector Search** technology. This tool allows users to chat with their own PDF data or pull live intelligence from the web.

### 🌟 Key Features
*   **Neon Dark UI:** Custom CSS-injected futuristic interface for a premium user experience.
*   **Dual-Engine Intelligence:** 
    *   **Private Mode:** Upload PDFs to create a local vector database for document-specific Q&A.
    *   **Global Mode:** Automatically falls back to DuckDuckGo web search when no local data is available.
*   **RAG Pipeline:** Utilizes `models/embedding-001` for high-accuracy document retrieval.
*   **Live Visuals:** Real-time market drift simulation using Plotly and Lottie animations.

### 🛠️ Technology Stack
*   **Framework:** Streamlit
*   **Brain:** Google Generative AI (Gemini 1.5 Flash)
*   **Search:** DuckDuckGo Search (DDGS)
*   **Data:** Pandas, NumPy, PyPDF2
*   **Styling:** Plotly, Lottie, Custom CSS


### 🧠 How it Works (Simple)
1. **Upload:** You feed the AI your business reports (PDFs).
2. **Search:** The AI turns your text into "math" to find the most relevant parts of your documents.
3. **Chat:** Gemini uses that context to give you precise, expert-level business advice.
