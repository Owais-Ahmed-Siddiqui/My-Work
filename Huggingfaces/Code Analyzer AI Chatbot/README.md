# 🛡️ CodeGuard AI — Lead Architect & Security Reviewer

CodeGuard (CMS) is an advanced AI-driven code auditing platform designed to identify security vulnerabilities, architectural flaws, and performance bottlenecks in real-time.

### 🌟 Project Essence
A "Security-First" mentor and auditor that bridges the gap between raw development and production-grade hardening. CodeGuard utilizes Large Language Models to provide instant, actionable intelligence for developers and students.

### ✨ Key Capabilities
*   **Deep Security Audits:** Scans source code for CWE-registered vulnerabilities and security anti-patterns.
*   **Learning Dashboard:** Provides instant metrics on Security Scores, Time Complexity (Big O), and Space Complexity.
*   **Automated Hardening:** Generates secure, "Pro-Fixed" versions of vulnerable code blocks instantly.
*   **AI Consultation:** A built-in chat interface for deep-diving into specific architectural decisions.
*   **Academic Toolkit:** Includes a Unit Test Generator and a "Viva/Interview Prep" engine for student project defenses.
*   **Premium Interface:** A gold-standard "Neon Dark" UI featuring glassmorphism, scanning animations, and a custom command center layout.

### 💻 Core Technology
*   **Brain:** Google Gemini 1.5 Flash (Generative AI)
*   **Framework:** Streamlit (Python-based Web Interface)
*   **Intelligence:** Regex-based block extraction & CWE vulnerability mapping.
*   **Design:** Custom CSS-injected Glassmorphism & Gold Gradient UI.
