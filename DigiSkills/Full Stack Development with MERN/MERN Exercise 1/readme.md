# MERN Exercise 1

## Personal Profile Web Page

This exercise focuses on creating a simple personal profile webpage using **HTML and CSS** and uploading the project to **GitHub**.

### What I Did

* Created a personal profile page using HTML.
* Added About Me, Skills, and Contact sections.
* Applied CSS for colors, spacing, borders, fonts, and layout.
* Made the page responsive.
* Initialized a Git repository using Git.
* Committed the project files.
* Uploaded the project to GitHub.

### Technologies Used

* HTML
* CSS
* Git
* GitHub
