# MERN Exercise 2

## Product Order Calculator & React Product Catalog

This exercise focuses on **JavaScript problem solving** and creating a **React product catalog** using Vite.

### What I Did

* Created product data using JavaScript.
* Displayed available products based on stock.
* Calculated subtotal, discount, and final total.
* Created an order invoice in the console.
* Created a React project using Vite.
* Built a reusable ProductCard component.
* Displayed products using an array and `map()`.
* Added responsive CSS styling.
* Used React state for the cart item count.
* Disabled the Add to Cart button for out-of-stock products.

### Technologies Used

* JavaScript
* React.js
* Vite
* CSS
* Git
