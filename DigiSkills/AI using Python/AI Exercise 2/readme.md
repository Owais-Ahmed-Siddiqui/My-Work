# Hands-on Exercise 02

In this exercise, I worked with the Titanic dataset using Python.

I loaded the dataset using Pandas and explored its rows, columns, statistics, and categorical data. I checked and handled missing values and prepared the data for machine learning.

I selected the features and the `Survived` column as the target. I split the data into training and testing sets and built an SVC classification model.

I evaluated the model using accuracy, confusion matrix, precision, recall, and F1-score. I also created visualizations to study survival based on gender, passenger class, and fare.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
