# Hands-on Exercise 01

In this exercise, I practiced basic Python programming and OOP concepts.

### Task 1

I created a Python program that takes sales amounts from 5 employees. I used a `for` loop and `if-elif-else` conditions to calculate tax based on the sales amount. I also calculated total sales and average sales.

### Task 2

I used NumPy to create an array of student marks. I displayed the original array and then converted it from integer to float data type.

### Task 3

I created a simple Bank Account System using OOP. I created `Customer` and `Account` classes and added functions for depositing money, withdrawing money, and checking the current balance.

## Tools Used

* Python
* NumPy
* VS Code
