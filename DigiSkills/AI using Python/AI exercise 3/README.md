# Toxic Comment Classifier 🤖🚫

A Deep Learning project designed to automatically detect and categorize toxic comments using Natural Language Processing (NLP).

### Simple Explanation
Imagine a "Smart Robot Brain" that reads internet comments. We taught it to understand which messages are mean and which are nice. We did this by cleaning up the text, turning words into numbers, and training the robot brain to recognize patterns of toxicity.

### 🛠️ Key Features
*   **Data Cleaning:** Preprocessed text by removing emojis, special characters, and numbers.
*   **NLP Pipeline:** Tokenization and Sequence Padding for Deep Learning compatibility.
*   **Deep Learning Architecture:** Built using TensorFlow/Keras with Embedding, Dropout, and Dense layers.
*   **Evaluation:** Detailed analysis using Accuracy, Loss curves, and Confusion Matrices.

### 🚀 Workflow
1. **Explore:** Analyze the dataset using Pandas (Shape, Info, Describe).
2. **Clean:** Handle duplicates, missing values, and normalize text.
3. **Process:** Tokenize text into numerical sequences and apply padding.
4. **Train:** Build and fit a Deep Learning model (ANN/LSTM) for 10-20 epochs.
5. **Evaluate:** Generate a Classification Report and Confusion Matrix to measure performance.

### 💻 Technologies Used
*   **Python**
*   **Pandas** (Data Manipulation)
*   **TensorFlow / Keras** (Deep Learning)
*   **Scikit-learn** (Evaluation Metrics)
*   **Matplotlib / Seaborn** (Visualization)
